Install and set up

A few minutes from download to your first agent. Flotilla checks what's missing and tells you how to fix it.

Download Flotilla

Flotilla runs on macOS 26 Tahoe or later.

  1. Download the latest release and drag Flotilla into your Applications folder.
  2. Open it. Flotilla is notarized by Apple, so it opens like any other app.
  3. Choose whether to share crash reports and usage data. They never include your code or conversations, and you can change your mind in Settings at any time.

Flotilla keeps itself up to date. When there's a new version it shows you what changed; you can also pick Check for Updates… from the Flotilla menu.

Let Setup check your Mac

Flotilla doesn't replace your coding agent. It runs the agents you already use, so it needs a few tools on your Mac. The first time you open it, Settings opens on the Setup tab and checks for them:

ToolWhy
gitEvery agent works in its own git checkout. Required.
Flotilla hook and CLIHow agents tell Flotilla what they're doing. Flotilla installs this itself. Required.
Claude Code, Codex or CursorThe agents. You need at least one.
GitHub CLIShows each agent's pull requests. Optional, but you'll want it.
Neovim or VimOnly if you'd rather edit in Vim than in Flotilla's editor.

Anything missing gets an Install button or a command to copy into Terminal. Once everything is green you'll see "Everything Flotilla needs is in place." Click Check Again after installing something.

For pull requests, sign the GitHub CLI in once with gh auth login. Flotilla uses your login and never sees your password.

Your terminal, as you like it

Flotilla's terminals are drawn by Ghostty and read your Ghostty config, so if you use Ghostty your font and theme already match. Agents also get everything your ~/.zshrc sets up, like your PATH, so they find the same tools you do.

That's it. Next, add a project and start your first agent.
