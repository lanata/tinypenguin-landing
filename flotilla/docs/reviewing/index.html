Reviewing the work

When an agent says it's done, see exactly what it changed, read the code around it, and send it notes without leaving its pane.

See what changed

Open the agent's Changes tab (⌃3). At the top, choose what to look at:

  • Uncommitted: what the agent has changed since its last commit.
  • Whole branch: everything on its branch compared with your main branch, commits included.

Pick a file on the left to read its diff, or All files to scroll through them all. The header shows the branch, how far it is ahead or behind, and whether it's been pushed.

Split the Changes tab beside the agent with ⌃⇧3 and watch the diff grow as it works.

Send the agent notes PRO

Spotted something? Hover over a line in the diff and click to comment on it, or comment on a whole file.

  1. Write what you'd like changed, like "use the existing date formatter here".
  2. Press ↩ to add the comment and keep reviewing.
  3. When you're through, click Send to Agent. All your comments go to the agent as one message, each pointing at its line.

In a hurry? ⌘↩ sends a single comment straight away.

Commit it yourself

Usually the agent commits its own work. If you'd rather, Commit & Push in the Changes tab commits every change with your message and pushes it. Hold ⌘ to commit without pushing.

Read the code

The Editor tab (⌃2) opens the agent's checkout in a proper code editor, with a file tree, syntax highlighting and saving as you type.

⌘POpen a file by typing part of its name.
⇧⌘FSearch every file.
⇧⌘PFind a function, type or property by name.
⌘-clickJump to where a name is declared.
⌘LGo to a line.

When an agent mentions a file in its terminal, like src/app.ts:42, ⌘-click it to open the file at that line.

Ask the agent about code

Select some code, or just put the cursor on a line, and press ⇧⌘A (Ask Agent). Write your question or request; ⌘↩ sends it to the agent along with exactly where in the code you mean. Press ↩ instead to collect several comments and send them together.

From the agent's own tab, ⌘P and ⇧⌘P drop a reference to a file or function into the agent's prompt, ready for you to finish the sentence.

Prefer Neovim? Choose it under Settings › Editor and it takes the editor's place in every pane.
