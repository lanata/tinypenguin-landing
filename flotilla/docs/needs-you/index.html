When an agent needs you

Agents work on their own until they need a decision. Flotilla makes sure you notice, and gets out of the way the rest of the time.

How you'll know

When an agent needs you, three things happen:

  • Its row in the sidebar turns red.
  • Its pane flashes, if it's on screen.
  • You get a notification, unless you're already looking at that agent. Click it to jump straight there.

Once you answer, the notification goes away by itself. You can turn notifications off in Settings › General.

Answering

Everything happens in the agent's own terminal, just as if you were running it yourself:

  • A question: type your answer and press ↩.
  • A plan to approve: read it, then accept it or tell the agent what to change.
  • A permission prompt, like running a command or editing a file: pick an option in the prompt.

Then the agent gets back to work and its row turns green again.

Good habits

  • Let the sidebar do the watching. Work on something else, or with another agent, until a row turns red.
  • Jump between agents with ⌥[ and ⌥], or press ⌘O and type part of an agent's name.
  • If the same permission prompt keeps coming up, you can let agents run that command without asking. See Fewer interruptions.

Telling an agent more

You can type into an agent's pane at any time, even while it's working, to add details or change course. To point it at a specific spot in the code, select the code in the editor and choose Ask Agent. There's more on that in Reviewing the work.
