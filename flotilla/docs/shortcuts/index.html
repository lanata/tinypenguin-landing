Keyboard shortcuts

You can do everything with the mouse, but a handful of keys make Flotilla fly. Here are the ones worth learning, starting with the most useful.

There's a pattern to them: ⌘ keys work the app, ⌥ keys work panes, and ⌃ keys work the tabs inside a pane. Plain keys always go to the agent.

Press ⌘/ in Flotilla for the full list, or hold it to peek.

Learn these first

⌘NNew agent
⌘OFind an agent
⌥D ⌥RSplit the pane down or right
⌥↩Zoom the pane
⌥[ ⌥]Previous or next running agent
⌘/Show every shortcut

Agents

⌥1 … ⌥9Open agent 1 to 9 in a new pane; add ⇧ to open it in this one
⌥WStop the agent
⌥QDelete the session
⌥⇧QDelete all completed sessions
⌥O ⌥XOpen the checkout in VS Code or Xcode

Panes

⌥⇧D ⌥⇧RSplit up or left
⌥SSmart Organize the grid
⌘⌥ arrows, ⌥H ⌥J ⌥K ⌥LMove focus between panes
⌥⇥Next pane; add ⇧ for the previous
⌥⇧WClose the pane; the agent keeps running

An agent's tabs

⌃1 … ⌃5Agent, Editor, Changes, Pull Requests, Terminal
⌃⇥Next tab; add ⇧ for the previous
⌃KBack to the agent
⌃⇧2 … ⌃⇧5Open that tab beside the agent
⌃⇧WClose the split

The app

⇧⌘NAdd a project
⌘1 ⌘2 ⌘3Projects, PRs, Routines
⌘SShow or hide the sidebar
⌘`Focus the sidebar; then ↑ ↓ to move, ↩ to open, esc to go back
⌘[ ⌘]Back or forward through where you've been
⌘TNew window tab
⌘= ⌘−Bigger or smaller text

The editor

⌘POpen a file
⇧⌘PFind a function, type or property
⇧⌘FSearch every file
⇧⌘AAsk the agent about the selection
⌘-click, ⌃⌘JJump to the declaration
⌘LGo to a line
