Arranging your workspace

Lay agents out side by side, zoom in on the one that matters, and keep each agent's tools one key away.

The grid

Agents show up in panes, tiled across the window. You'll mostly use four keys:

⌥D ⌥RSplit the pane down or to the right. Add ⇧ to split up or to the left.
⌥↩Zoom the pane to fill the window, and press again to put it back. Double-clicking a pane's header does the same.
⌥SSmart Organize: lay every open pane out evenly in one go.
⌥⇧WClose the pane. The agent keeps running and you can open it again from the sidebar.

To move between panes, use ⌘⌥ with the arrow keys, or ⌥H ⌥J ⌥K ⌥L if you think in Vim.

Prefer the mouse? Drag an agent from the sidebar onto the edge of a pane to split there, or onto its middle to replace it. Drag a pane's header to move it.

Each agent's tabs

Every pane has a row of tabs in its header, all working in that agent's checkout:

  • The agent ⌃1: its terminal.
  • Editor ⌃2: browse and edit the agent's files.
  • Changes ⌃3: what the agent changed, as a diff.
  • Pull Requests ⌃4: its pull requests, checks and reviews.
  • Terminal ⌃5: a shell of your own in the checkout, to run the app or poke around.

⌃⇥ cycles through them and ⌃K takes you back to the agent. Want to watch the agent and its changes at the same time? Add ⇧, as in ⌃⇧3, to open a tab beside the agent instead of over it. ⌃⇧W closes that split.

Windows and tabs

Press ⌘T for a new window tab with a grid of its own, handy for keeping one project per tab. Each window has its own sidebar too. ⌘S hides the sidebar when you want the room.

Small things that help

  • ⌘[ and ⌘] go back and forward through the panes, tabs and files you've visited.
  • ⌘= and ⌘− make the text bigger or smaller.
  • Click an agent's name in its pane header to see its project, branch, checkout path and how much context it has left.
  • ⌥O opens the agent's checkout in VS Code, and ⌥X in Xcode.
  • Forgot a shortcut? Press ⌘/, or hold it to peek. Every shortcut is also in the menu bar.
