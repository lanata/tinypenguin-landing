Arranging your workspace

Lay agents out side by side, zoom in on the one that matters, and keep each agent's tools one key away.

The grid

Agents show up in panes, tiled across the window. You'll mostly use four keys:

⌥D ⌥RSplit the pane down or to the right. Add ⇧ to split up or to the left.
⌥↩Zoom the pane to fill the window, and press again to put it back. Double-clicking a pane's header does the same.
⌥SSmart Organize: lay every open pane out evenly in one go.
⌥⇧WClose the pane. The agent keeps running and you can open it again from the sidebar.

A new pane starts out empty, with a list of what to put in it. Press ↩ to start a new session there, or ↓ to walk through the sessions that aren't on screen and ↩ to open one. Fork a session… at the foot of the list (one ↑ from the top) lets you pick any session to fork, and esc takes you back. Whatever you choose opens in that pane, so ⌥D then ↩ is a new session right below the one you were in.

To move between panes, use ⌘⌥ with the arrow keys, or ⌥H ⌥J ⌥K ⌥L if you think in Vim.

Prefer the mouse? Drag an agent from the sidebar onto the edge of a pane to split there, or onto its middle to replace it. Drag a pane's header to move it.

Each agent's tabs

Every pane has a row of tabs in its header, all working in that agent's checkout:

  • The agent ⌃1: its terminal.
  • Editor ⌃2: browse and edit the agent's files.
  • Changes ⌃3: what the agent changed, as a diff.
  • Pull Requests ⌃4: its pull requests, checks and reviews.
  • Terminal ⌃5: a shell of your own in the checkout, to run the app or poke around.

⌃⇥ cycles through them and ⌃K takes you back to the agent. Want to watch the agent and its changes at the same time? Add ⇧, as in ⌃⇧3, to open a tab beside the agent instead of over it. ⌃⇧W closes that split.

Your own tabs and buttons

Put the things you do all the time one click away in agents' panes: run the tests, open lazygit, or tell the agent to push. In Settings › Commands, choose whether a command is for every agent or one project's, add it, give it a name and an icon, and pick its kind:

  • Tab: a tab after the agent's other tabs that runs a command in its checkout, like your tests. When the command ends, it waits for a key so you can read the result. Right-click the tab to open it beside the agent.
  • Popup: a button that runs a command in a window over the grid, for tools you work in like lazygit. It closes when the command ends; if the command failed, it waits for a key so you can read why. ⌘W or a click outside closes it early.
  • In the background: a button that runs a command with no window. The button lights up while it runs. If the command fails, a popover on the button shows the end of its output, with Run Again; when it finishes, the bottom of the sidebar says so.
  • Message to the agent: a button that sends the agent a message, as if you had typed it, like "Commit what's done and push it" or a slash command.

Buttons sit in the pane's header, just before its tabs. Commands run with the same environment as the agent. A project's commands come after the ones every agent has; you can also reach them from Edit Project.

To share commands with everyone on a repo, add them to its settings file instead. Everyone who works on the repo gets them, and Flotilla asks before running one the first time.

Give a command a key too, and ⌃⌥ with that key runs it for the focused agent, as in ⌃⌥G for lazygit. ⌃⌥ is all yours: none of Flotilla's own shortcuts use it. Your commands are in the Pane menu and the ⌘/ guide too, and a few ready-made ones are under Add Command.

Windows and tabs

Press ⌘T for a new window tab with a grid of its own, handy for keeping one project per tab. Each window has its own sidebar too. ⌘S hides the sidebar when you want the room.

Small things that help

  • ⌘[ and ⌘] go back and forward through the panes, tabs and files you've visited.
  • ⌘= and ⌘− make the text bigger or smaller.
  • ⌘F finds text in the terminal you're in. ⌘G and ⇧⌘G step through the matches.
  • An agent's terminal keeps its whole history: scroll, select and copy it like in any terminal, and ⌘F searches all of it. Claude Code agents run in Claude's fullscreen view, which keeps the conversation itself and scrolls with the mouse wheel.
  • Click an agent's name in its pane header to see its project, branch, checkout path and how much context it has left.
  • ⌥O opens the agent's checkout in VS Code, and ⌥X in Xcode.
  • Forgot a shortcut? Press ⌘/, or hold it to peek. Every shortcut is also in the menu bar.
