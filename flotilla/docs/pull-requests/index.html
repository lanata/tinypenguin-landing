Pull requests and wrapping up

Follow each agent's pull request from draft to merged without leaving Flotilla, then clear the agent away in one step.

Follow the pull request

When an agent opens a pull request, Flotilla picks it up on its own. It shows up in three places:

  • The agent's row in the sidebar, with its checks and review status: "#42 · 2 pending", "#42 approved".
  • A chip under the agent's terminal. Click it to open the pull request, or ⌘-click to open it on GitHub.
  • The PRs list in the sidebar (⌘2), with all your open, draft and recently closed pull requests.

This needs the GitHub CLI signed in. See Install and set up.

Everything in one tab

The agent's Pull Requests tab (⌃4) has what you'd go to GitHub for:

  • Conversation: the description, comments and review threads. Reply and resolve threads right there.
  • Files: the diff, where you can leave comments on lines.
  • Checks: CI results. Re-run failed checks or open a check's log.

Below that are the reviewers, labels and assignees, and the merge box. When it says "Ready to merge", click Merge pull request, or Enable auto-merge to merge once checks pass. From the ⋯ menu you can also mark a draft ready for review, or close the pull request.

Writing comments, replies and reviews with a message needs Pro. Reading everything, approving and merging are free.

Got review feedback? Just tell the agent "address the review comments on the PR". It can read them itself.

Pick up any pull request

In the PRs list, right-click a pull request and choose Start Agent on… to start an agent on its branch, for example to fix a failing check on a teammate's pull request.

Done with an agent?

Once its work is merged, delete the agent: press ⌥Q, or right-click its row and choose Delete Session. That stops it and removes its checkout. Its branch stays.

Before deleting, Flotilla checks that nothing would be lost. If the agent is mid-task, has a pull request still open, or has changes that aren't committed or pushed, it tells you exactly what, and you can still choose Delete Anyway.

To clear out a whole batch at once, press ⌥⇧Q (Delete All Completed Sessions). It deletes every agent whose pull requests are merged or closed and that has nothing left to lose, and leaves the rest alone.

Stop, without deleting

Not finished, but want an agent out of the way? ⌥W stops it. Its checkout and conversation are kept, and opening it again picks up the conversation where it left off.

Bring one back PRO

Deleted something too soon? Right-click the project's name and choose Session History…. Click Resume to bring an agent back with its branch and its conversation.
