Fewer interruptions

Most permission prompts are for the same handful of commands. Tell Flotilla which ones you trust and spend your attention where it matters.

Always allow the commands you trust PRO

Go to Settings › Permissions and add a rule under Always Allowed for each thing agents may do without asking. Rules are written the way Claude Code writes them:

Bash(npm test)Run the tests.
Bash(git status)Check git status.
Bash(npm run lint *)Run the linter with any arguments.
WebSearchSearch the web.

When an agent asks to do something on the list, Flotilla answers for you and the agent keeps going. Everything else still asks. Rules apply to every Claude Code and Codex agent.

Start small. Add a rule the third time you find yourself approving the same thing.

Auto-approve one agent PRO

For a task you trust completely, you can let one agent approve every one of its own requests. First allow it in Settings › Permissions (you'll be asked to confirm that you understand the risk). Then right-click the agent and choose Auto-Approve Permission Requests.

A shield shows on its row and pane while it's on. Click the shield to turn it off.

An auto-approving agent can run any command and change any file it can reach. Use it for work you'd be happy to let run unattended, and keep an eye on it.

Walk away while agents work PRO

Flotilla keeps your Mac from sleeping while any agent is working, so you can step away from a long task. In Settings › Agents you can also keep the display on, and choose what happens on battery: stay awake, stay awake for an hour, or let the Mac sleep.

The cup in the sidebar's footer shows when it's keeping your Mac awake, and which agents are working.

Tell every agent once PRO

Have instructions you give every agent, like "use pnpm, not npm" or "write tests first"? Put them in Settings › Prompt and they're added to every Claude Code and Codex agent's instructions.

Claude Code updates

When Claude Code updates itself, agents still on the old version show an Update button in their pane's header. Click it to restart the agent on the new version; its conversation carries on. To have idle agents do this on their own, turn on Restart idle agents onto Claude Code updates in Settings › Agents.
