Flotilla

Run a fleet of coding agents on your Mac.

Claude Code, Codex and Cursor agents side by side, each in its own checkout and its own pane, with a sidebar that tells you who's working and who needs you.

  • Tile, zoom and switch agents from the keyboard
  • Pull requests, CI and review state built in
  • Routines that run agents on a schedule
